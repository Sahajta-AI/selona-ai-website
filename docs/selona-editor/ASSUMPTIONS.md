## 27 Nov: Claude gets full control (Pranamya's decision)

- **Claude can publish.** Pranamya asked for Claude to do everything the editor can. The connector now has tools to change text, lists and pictures, show and undo pending changes, publish, undo the last publish, save a version, bring one back and restore as a draft. This replaces the brief's "drafts only" rule. Safeguards: `publish` needs the `draft_id` of the draft the person previewed and refuses if the draft changed since; the three tools that change the live site are marked `destructiveHint`, so Claude asks before using them; the server instructions tell Claude to preview first and publish only when asked. Since a connector address can now publish, it must be kept private like a password. Removing its entry from `EDITOR_CONNECTOR_TOKENS` switches it off at once.
- **History marks Claude.** Everything done through the connector is recorded as `<email> (via Claude)`. Drafts carry a `claude` flag while they hold changes saved by Claude, so a publish from the editor that includes them shows "Includes changes made with Claude".
- **Sign in once.** Sessions now last 30 days (they were 8 hours). The allowlist is still checked on every request, and changing `EDITOR_SESSION_SECRET` signs everyone out.
- **Review links sign you in.** Pranamya was asked to sign in again after opening a review link from Claude (most likely the link opened in a different browser or window). Links are now `/editor/open?t=<ticket>&next=…`. The ticket is HMAC-signed for one allowed email, lasts 24 hours and can't be used as a session cookie (separate purpose field). Someone already signed in keeps their own session. An expired link goes to sign-in and then on to the same review. Trade-off: anyone who sees the link within 24 hours could open the editor as that person. That's the same reach the connector address already has.
- **Back to where you were.** Signing in from `/editor?review=1&path=…` now returns you there (before, you landed on the plain editor).
- **Pictures from Claude:** `replace_picture` takes a public https address or base64 bytes (about 3 MB through base64, because of Vercel's 4.5 MB request limit), checks the file's first bytes, and keeps the 4 MB limit. Addresses are checked against private and internal networks on every redirect (at most 3) before downloading. Unlike editor uploads, these aren't compressed.
- **Screenshots:** Claude reads the words in a screenshot itself. `find_text` ignores case, spacing, line breaks, quote and dash styles, and suggests the closest texts when a word was misread.
- **Connector address in a browser / standing stream:** `GET` with an event-stream request and `DELETE` answer 405 (stateless server). Before, they stayed open until Vercel's 300 s limit.
- Publish from the editor now sends the draft id it saw; a draft changed by Claude (or anyone) in between is refused with the "Someone else changed this draft" warning.

## 27 Nov: audit fixes

- **Sign-in limit:** 5 wrong keys lock an email only from that network address; 20 lock the address. Before, 5 wrong keys locked the email everywhere, and Mr Rahul's email is public (it's in the contact form's code), so anyone could keep him out. Keys are 256-bit, so the email-wide limit added no protection.
- **History in pages:** the editor and Claude show 20 versions at a time with "Show older" (`older_published` / `older_saved` for Claude), using one function (`historyPage`). Before, the editor stopped at 100 and Claude at 50, so old versions, and eventually "Original site", couldn't be reached. Pages read only the 20 versions they show.
- **Private addresses:** picture downloads now use Node's `net.BlockList`, which also catches IPv6 spellings of private IPv4 addresses (`[::ffff:10.0.0.1]` got past the old check).
- **Saves at the same moment:** if two saves both pass the "has anyone changed it?" check, the one written second puts the first back on top as a copy (`copyOf`) and gets the "Someone else changed this draft" warning. A copy counts as the same draft for the person who saved it, so they get no false warning. Limit: a save the store hasn't listed yet can still slip past.
- **Removed:** unused helper exports, three one-off July scripts (and the `sharp` and `playwright` dev dependencies; Next.js brings its own `sharp`), and seven unused files in `public/`.
